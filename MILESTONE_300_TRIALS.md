## Statistical Methods Available

### Implemented and Validated:
1. **Traditional Meta-Analysis**
   - Random-effects (REML, DerSimonian-Laird, Paule-Mandel)
   - Fixed-effect
   - Hartung-Knapp adjustment

2. **Meta-Regression**
   - Continuous covariates (age, LVEF, BP, LDL reduction)
   - Categorical covariates (etiology, era, geography)
   - Multiple predictor models
   - R² for heterogeneity explained

3. **Dose-Response Meta-Analysis**
   - Linear, quadratic, restricted cubic splines
   - Tests for nonlinearity
   - Optimal dose identification

4. **Network Meta-Analysis**
   - Direct and indirect comparisons
   - Consistency checking
   - SUCRA rankings
   - Treatment hierarchy

5. **Publication Bias Methods**
   - Funnel plots, Egger's test
   - Trim-and-fill
   - Selection models (Bartoš 2024)
   - P-curve analysis

6. **Robust Methods**
   - Outlier detection (Huber weights, Noma 2024)
   - Influence diagnostics
   - Leave-one-out sensitivity

7. **Bayesian Methods**
   - Beta-binomial for rare events
   - Hierarchical models
   - Prior sensitivity analysis

All methods tested and validated on real cardiovascular data.
